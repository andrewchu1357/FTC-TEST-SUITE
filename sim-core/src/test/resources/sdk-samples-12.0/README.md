# FTC SDK 12.0 sample OpModes

Copied unchanged from FIRST's FtcRobotController v12.0
(`FtcRobotController/src/main/java/org/firstinspires/ftc/robotcontroller/external/samples/`),
under FIRST's BSD-style license (in each file's header).

`SdkSamplesTest` compiles each one against the simulator's SDK stand-in (`sdk-shim`), the way a
team's copy of a sample would be compiled, so a missing SDK class or method shows up as a test
failure. The test lists the samples that aren't expected to compile yet, and why.
